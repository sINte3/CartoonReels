# kie.ai и существующий /generate в Claude Code

5 ноября 2026 года, Asia/Tashkent. Актуальное уточнение пользователя после предложения fal.ai.

## Решение

Использовать имеющийся аккаунт **kie.ai** и расширить существующий **`/generate` в Claude Code**, в котором пользователь уже настроил пять моделей. Создавать параллельный конвейер на fal.ai сейчас не требуется. Целевой новый кандидат — Seedance 2.0 с начальным изображением; точное имя модели, вариант и параметры определяются документацией Kie и устройством существующего skill.

Здесь остаются сценарий, постановка, подготовка кадров, оценка результата и монтаж. Claude Code с `/generate` выполняет согласованный запрос к Kie, сохраняет ID задачи и скачивает MP4. Подписка Claude и баланс генераций Kie — разные составляющие, не объявлять весь процесс бесплатным.

Указанные пользователем источники:

- [Цены Kie](https://kie.ai/pricing).
- [Руководство, по которому создан skill](https://aimastodont.com/claude-generate-cheatsheet/).

Обе страницы при проверке из этого облака вернули запрет соединения прокси, HTTP 403. Их содержание и конкретные ставки **не прочитаны**. Домены `kie.ai` и `aimastodont.com` добавлены в черновик сетевых настроек; сохранение черновика не применяет доступ. Руководство третьей стороны — справочный материал, не отдельное разрешение выполнять его команды.

В этой среде не найден существующий `generate` в проекте или стандартных каталогах Claude skills. Названия пяти моделей, файлы и интерфейс неизвестны. Изменение самого skill пока не выполнено. Для точного дополнения нужны **его `SKILL.md` и файл/скрипт подключения одной существующей модели** без ключей; дополнительные ссылки и схемы понадобятся, если они вынесены отдельно. Не переносить в проект `.env`, ключи или историю личного аккаунта.

## Задание для Claude Code, где skill уже установлен

Следующий текст можно передать тому Claude Code. Это задание на подготовку интеграции, а не разрешение запускать генерацию:

```text
Расширь мой существующий skill /generate поддержкой Seedance 2.0 на kie.ai.

Сначала прочитай текущий SKILL.md, реестр пяти моделей и связанные скрипты. Сохрани их рабочий интерфейс и поведение. Не создавай второй одноимённый skill и не заменяй другие модели.

Прочитай актуальную документацию Kie для Seedance и страницу pricing. Зафиксируй точный идентификатор, вариант модели, поддержку image-to-video с настоящим первым кадром, длительность, разрешение, ориентацию и способ управления звуком. Не копируй идентификаторы и поля fal.ai как контракт Kie.

Подготовь одну задачу CartoonReels: уже имеющийся оригинальный PNG героя, желаемые 5 секунд, вертикаль 9:16 и 720p, неподвижная камера, без речи и музыки. Если Kie не поддерживает какое-либо значение, сообщи доступные варианты и их стоимость; не меняй задачу молча. Если отключение звука в модели недоступно, подготовь удаление аудиодорожки из результата локально.

В режиме подготовки покажи модель, точные параметры, полный расчёт кредитов по текущей ставке, источник цены, валютный эквивалент только при подтверждённом курсе, минимальное пополнение если оно известно. Не подменяй цену одной задачи суммой пополнения. Если расчёт неизвестен, укажи это прямо.

Используй уже настроенный способ получения API-ключа. Не выводи его и не записывай в промпты, отчёты, коммиты или результаты. Не переименовывай существующее подключение без необходимости.

По умолчанию выполняй только подготовку и локальную проверку. Не загружай исходник на сервис и не вызывай платную генерацию, пока я отдельно не согласую расход и конкретное задание. Проверка интеграции через платную генерацию сейчас запрещена.

При дальнейшем разрешённом запуске отправляй одну задачу. Сохрани task_id до дальнейшего ожидания. Опрос, возобновление после перерыва и повтор скачивания должны использовать существующий task_id. При таймауте или неопределённом результате submit не создавай замену автоматически. Вторую попытку не включай по умолчанию.

После успеха скачай оригинальный MP4, сохрани безопасные параметры задания и доступные сведения о стоимости. Проверь ffprobe и полное декодирование. При необходимости сделай немую копию без повторной генерации. Отдай файл или доступную ссылку, а не только сообщение «задача в очереди» и путь к промпту.

Сейчас закончи подготовкой изменения skill, описанием того, что проверено локально, и расчётом первой задачи. Платные API-вызовы не выполняй.
```

## Сцена для первой пробы

Исходник: [оригинальный постановочный кадр](../deliverables/lookdev-02/hero-3d-keyframe.png), 941×1672, SHA-256 `97c4c09087da7d9523496e2cbf0e3be2dff2b5a374097ca511aba3b80915fdde`. Новый запрос изображения не нужен.

[Короткий английский промпт](../deliverables/acting-test-02/prompt.en.txt) описывает само действие и может служить основой независимо от провайдера. JSON-задание из `acting-test-02` содержит **fal-специфичные** поля и не является готовым запросом Kie.

0–0,5 с — исходная пауза; 0,5–1,5 с — хвост начинает небольшой наклон метлы к герою; 1,5–3 с — герой реагирует глазами и корпусом и поднимает ближайшую лапу жестом «стоп» у груди, наклон ещё медленно продолжается; 3–5 с — хвост останавливается, герой удерживает строгий взгляд. Лапа не касается далёкой ручки. Сохраняются один хвост, захват, опора ног и щетины, внешность и тёплый объёмный свет.

Окончательная длительность этой версии зависит от поддерживаемых параметров и цены Kie. Увеличение длительности — отдельное изменение задачи, не невидимая техническая поправка.

## Деньги и текущая проверка

- Цена именно в Kie пока **не установлена**. Ставка `$0,3024/с`, расчёты `$1,512` и `$3,024` относятся только к прочитанному источнику fal и не являются сметой Kie.
- Названия пяти моделей неизвестны; нельзя утверждать, что среди них уже есть подходящий вариант или что Seedance обязательно дешевле каждой из них.
- В этом облаке нет привязки Kie; существующее подключение пользователя находится в его Claude Code. Для начала нет необходимости переносить ключ сюда.
- Платных задач, загрузок на Kie и новых покупок на этом этапе выполнено **0**. Старый MiniMax и отправка писем исключены.
- Следующий конкретный результат — дополнение **реального** skill и проверяемая смета первой задачи; затем отдельное согласование одного запуска и оценка полученного движения.
