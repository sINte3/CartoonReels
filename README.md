# CartoonReels

Облачный проект оригинальных коротких бессловесных мультфильмов. Рабочая концепция — **«Хвост спешит помочь»**: самостоятельный хвост слишком усердно помогает рыжему хозяину. Визуальная основа — объёмный стилизованный 3D-персонаж, тактильная шерсть, тёплый свет и жилая комната. Окончательный бренд и художественная приёмка пользователя ещё не утверждены.

## Текущая цель — первый законченный релиз

**09.11:** пользователь допускает EP001/EP002 как тестовые клипы, но для релиза требует кульминацию и логичную концовку. Поэтому следующий шаг — **[EP003 «Кому медаль?»](episodes/EP003/README.md)**: существующие 7 секунд становятся завязкой; новый отдельный подъём хвостом доказывает, кто силач; медаль на хвосте и аплодисменты хозяина завершают историю. Около 16 секунд, два новых плана 5 + 4 с, три новые постановки. По старым ставкам новая база 405 кредитов, с названным резервом до 634; новых расходов не разрешено и не сделано. Готовы текстовая раскадровка, манифест и фактический кадр начала для продолжения.

## Текущий сценарий — «Чисто. Почти.»

**08.11: получен выпуск со звуком и подготовлен бесплатный монтажный вариант.** [Просмотр: оригинал 8 с и монтаж 6,5 с](deliverables/ep001-v3/README.md). По пользовательскому отчёту внешнего Claude Code пакет стоил 388 кредитов из 600. Новых расходов здесь нет; художественная приёмка ожидается.

**[EP001 V3: история, раскадровка и производственный план](episodes/EP001_V3/README.md)**. Восемь секунд, два плана:

1. Самодовольный герой командует уборкой. Хвост сметает пыль ему в лицо: пол чистый, герой грязный.
2. Герой чихает, пыль снова на полу. Хвост готовит новый взмах, а герой уже испуганно защищается двумя лапами. Конец перед повтором.

## Как продолжать

Для нового Claude Code открыть `E:\CartoonReels`, проверить ветку и чистоту дерева, обновить чистый `main` через `git pull --ff-only`. Читать `CLAUDE.md`, `PROJECT_STATE.md`, общую дорожную карту, правила серии и [README исполнителя](tools/kie-executor/README.md), затем текущий **разбор EP002** и его production-записи. Полный пакет EP002 уже выполнен. V3 уже выполнен; его [записи семи задач](episodes/EP001_V3/production/README.md) и скрипты сохраняются для истории и адаптации. Саму адаптацию под 4 + 5 с / 9 с / 216 кадров проверить отдельно до расходов. Не настраивать уже работающий конвейер заново и не переносить API-ключи в чат.

Remotion используется для монтажа и звука, FFmpeg — для проверки и экспорта. Существующая среда редактора проверена; инструкции в [animation/README.md](animation/README.md). Работать в текущем checkout, worktree без прямого запроса не создавать. Рабочий рендер не является доказательством понятного юмора.

Пользователь разрешил передачу подготовленного проекта и небольших готовых результатов через этот GitHub независимо от видимости. Для скачивания файла использовать Download raw file. Новые личные входные материалы, исходный RainPilot, ключи, `.env` и зависимости не загружать автоматически. Для большого медиаархива отдельное хранилище пока не подключено. Социальная публикация и новые расходы не разрешаются выбором концепции.

RainPilot завершён и не переделывается.
