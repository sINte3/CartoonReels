# CartoonReels

Облачный проект коротких оригинальных бессловесных мультфильмов. Рабочее направление — **«Хвост спешит помочь»**: самостоятельный хвост слишком старательно помогает своему хозяину и создаёт бытовые комические ситуации.

Концепцию выбрал ассистент 15 октября 2026 года по прямому поручению пользователя. Это рабочее название серии; окончательный бренд и внешний вид ещё не проверены.

## Продолжение работы

1. Прочитать `PROJECT_STATE.md` и `DECISIONS.md`.
2. Для первого выпуска использовать `episodes/EP001_BRIEF.md`.
3. Продолжать бесплатную подготовку и постановку полного EP001. Платные генерации, расход внешних генеративных квот и публикации роликов в соцсетях пока не разрешены. Загрузка подготовленных файлов в этот GitHub-репозиторий отдельно разрешена пользователем независимо от его видимости.
4. Работать в существующем checkout. Новый Git worktree без прямого запроса не создавать.

Основной движок сборки — Remotion с повторно используемым 2D-ригом; FFmpeg/ffprobe — для проверки MP4. Проект создан в `animation/`: есть лист шести поз и восьмисекундная немая проба движения. Рендер 192 кадров, 1080×1920, 24 fps и полное декодирование прошли. Инструкции — `animation/README.md`. Полный EP001 ещё не собран. Устанавливать второй движок для того же выпуска не требуется.
