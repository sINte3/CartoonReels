# CartoonReels

Облачный проект оригинальных коротких бессловесных мультфильмов. Рабочая концепция — **«Хвост спешит помочь»**: самостоятельный хвост слишком усердно помогает рыжему хозяину. Визуальная основа — объёмный стилизованный 3D-персонаж, тактильная шерсть, тёплый свет и жилая комната. Окончательный бренд и художественная приёмка пользователя ещё не утверждены.

## Общий план и следующий выпуск

**[Цель проекта, стадия и дорожная карта](docs/PROJECT_ROADMAP_RU.md)** · [Рабочие правила серии](docs/SERIES_GUIDE_RU.md).

Сейчас проверяем серийный формат на первых трёх пилотах: один уже получен. По поручению продолжить подготовлены [три новых сюжета](episodes/EP002/STORY_OPTIONS_RU.md); для **[EP002 «Силач понарошку»](episodes/EP002/README.md)** выбраны два плана 4 + 5 секунд. Гантель поднимает хвост, а хозяин слишком рано гордится своей силой. При последних сообщённых ставках база — 405 кредитов, все перечисленные исправления — до 634; предлагаемый будущий лимит 640 не активирован. Готовы пять промптов, манифест, [единое задание на весь EP002](episodes/EP002/CLAUDE_PRODUCE_FULL_RU.md) и [альтернатива только для сметы](episodes/EP002/CLAUDE_PREPARE_ONLY_RU.md). После прямой активации пакета до 640 свежая бесплатная проверка цены/баланса входит в начало исполнения; OK на каждом этапе не нужен. Финальная смена статуса выражена глубоким приседом; сборка 4 + 5 с проверена технически на старом материале. Новых изображений, видео и расходов нет.

**08.11: получен выпуск со звуком и подготовлен бесплатный монтажный вариант.** [Просмотр: оригинал 8 с и монтаж 6,5 с](deliverables/ep001-v3/README.md). По пользовательскому отчёту внешнего Claude Code пакет стоил 388 кредитов из 600. Новых расходов здесь нет; художественная приёмка ожидается.

**[EP001 V3: история, раскадровка и производственный план](episodes/EP001_V3/README.md)**. Восемь секунд, два плана:

1. Самодовольный герой командует уборкой. Хвост сметает пыль ему в лицо: пол чистый, герой грязный.

## Как продолжать

Для нового Claude Code открыть `E:\CartoonReels`, проверить ветку и чистоту дерева, обновить чистый `main` через `git pull --ff-only`. Читать `CLAUDE.md`, `PROJECT_STATE.md`, общую дорожную карту, правила серии и [README исполнителя](tools/kie-executor/README.md), затем актуальный **пакет EP002**. V3 уже выполнен; его [записи семи задач](episodes/EP001_V3/production/README.md) и скрипты сохраняются для истории и адаптации. Саму адаптацию под 4 + 5 с / 9 с / 216 кадров проверить отдельно до расходов. Не настраивать уже работающий конвейер заново и не переносить API-ключи в чат.

Remotion используется для монтажа и звука, FFmpeg — для проверки и экспорта. Существующая среда редактора проверена; инструкции в [animation/README.md](animation/README.md). Работать в текущем checkout, worktree без прямого запроса не создавать. Рабочий рендер не является доказательством понятного юмора.

Пользователь разрешил передачу подготовленного проекта и небольших готовых результатов через этот GitHub независимо от видимости. Для скачивания файла использовать Download raw file. Новые личные входные материалы, исходный RainPilot, ключи, `.env` и зависимости не загружать автоматически. Для большого медиаархива отдельное хранилище пока не подключено. Социальная публикация и новые расходы не разрешаются выбором концепции.

RainPilot завершён и не переделывается.
