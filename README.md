# CartoonReels

**Актуальная поправка:** пользователь отверг визуальный уровень первой SVG-пробы. Следующий этап — постановочные изображения и короткие актёрские сцены в объёмной стилизованной 3D-эстетике, ориентир — присланный RainPilot. [Новое художественное задание](docs/ART_DIRECTION_V2.md) имеет приоритет над старой 2D-постановкой. `study-01` хранится как история технической проверки, а не принятый стиль канала.

Облачный проект коротких оригинальных бессловесных мультфильмов. Рабочее направление — **«Хвост спешит помочь»**: самостоятельный хвост слишком старательно помогает своему хозяину и создаёт бытовые комические ситуации.

Концепцию выбрал ассистент 15 октября 2026 года по прямому поручению пользователя. Это рабочее название серии; окончательный бренд и внешний вид ещё не проверены.

## Продолжение работы

1. Прочитать `PROJECT_STATE.md` и `DECISIONS.md`.
2. Сначала использовать `docs/ART_DIRECTION_V2.md`; `episodes/EP001_BRIEF.md` сохраняется как ранний сценарий, требующий новой постановки.
3. Новый 3D-кадр уже получен одним отдельно разрешённым запросом; пользователь ответил «Уже лучше». [Одна 5-секундная актёрская проба](deliverables/acting-test-01/README.md) подготовлена, но не запущена: известны M plan и баланс 800 кредитов; пользователь подтвердил, что цена задачи не показывается. Числовая смета неизвестна, расход не согласован; текст для поддержки подготовлен в материалах пробы. Новые генерации и публикации роликов в соцсетях пока не разрешены. Загрузка подготовленных файлов в этот GitHub-репозиторий отдельно разрешена пользователем независимо от его видимости; новый пользовательский референс в него не загружать автоматически.
4. Работать в существующем checkout. Новый Git worktree без прямого запроса не создавать.

Remotion остаётся рабочим инструментом сборки, темпа и экспорта; FFmpeg/ffprobe — технической проверки MP4. Ранний проект `animation/` подтверждает работоспособность среды: 192 кадра, 1080×1920, 24 fps, полное декодирование. Его SVG-дизайн и актёрская проба отклонены пользователем по художественному уровню; продолжать их полировку вместо нового направления не нужно. Полный EP001 ещё не собран.
