## Продолжение работы

1. Прочитать `PROJECT_STATE.md` и `DECISIONS.md`.

Использовать [новую пробу на Seedance 2.0](deliverables/acting-test-02/README.md), её смету и промпт. `acting-test-01` — архив прежнего пути; не возвращаться к его оплате, письмам или повторной генерации. Новые генерации и публикации роликов в соцсетях пока не разрешены. Загрузка подготовленных файлов в этот GitHub-репозиторий отдельно разрешена пользователем независимо от его видимости; новый пользовательский референс в него не загружать автоматически.
4. Работать в существующем checkout. Новый Git worktree без прямого запроса не создавать.

Remotion остаётся рабочим инструментом сборки, темпа и экспорта; FFmpeg/ffprobe — технической проверки MP4. Его SVG-дизайн и актёрская проба отклонены пользователем по художественному уровню; продолжать их полировку вместо нового направления не нужно. Полный EP001 ещё не собран.
