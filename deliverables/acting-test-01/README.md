# Актёрская проба 01 — «Хватит помогать»

15 октября 2026 года, Asia/Tashkent. **Подготовка; видео ещё не сгенерировано.**

На новый 3D-кадр пользователь ответил «Уже лучше» и поручил продолжать. Это положительная оценка направления; качество движения ещё предстоит проверить. Следующий результат — один непрерывный вертикальный план длительностью 5 секунд.

## Исходный кадр и действие

[Скачать оригинальный PNG](../lookdev-02/hero-3d-keyframe.png). Использовать его как **первый кадр / image-to-video**, а не просто как свободный референс внешности. Новое изображение не заказывать.

Хвост чуть наклоняет удерживаемую метлу к герою; герой слегка отшатывается, поднимает ближайшую переднюю лапу у груди жестом «стоп» и строго смотрит на хвост. Метла замирает. Лапа **не касается ручки**: в исходном изображении расстояние слишком велико. Это уточнение прежнего задания, где предполагался контакт лапы со щёткой. Здесь проверяются игра героя и уже существующий контакт хвост–метла; контакт лапы с предметом этим тестом не проверяется.

| Время | Действие |
| --- | --- |
| 0–0,5 с | Исходная поза, короткая пауза. |
| 0,5–1,5 с | Хвост начинает медленный небольшой наклон ручки влево по экрану, к герою. Щетина опирается на пол; захват не скользит. |
| 1,5–3 с | Наклон медленно продолжается, суммарно лишь на несколько градусов. Глаза следят за метлой; корпус немного отклоняется от метлы. Ближайшая к метле передняя лапа поднимается у груди в коротком жесте «стоп». Обе задние лапы сохраняют опору. |
| 3–5 с | Хвост прекращает действие; метла неподвижна в достигнутом положении. Герой удерживает строгий взгляд, затем следует комедийная пауза. |

Камера неподвижна, без склеек и изменения крупности. Сохраняются внешность, шерсть, свет, комната, одна метла и один непрерывный хвост. [Готовый английский промпт](prompt.en.txt) можно скопировать целиком.

## Рекомендуемый способ первой пробы

Использовать уже имеющийся **MiniMax Cloud → video-creator → MiniMax-H3**. Это рекомендация по присланному интерфейсу, а не подтверждение управления приложением из Codex: такого подключения здесь нет.

1. Прикрепить оригинальный PNG и выбрать режим первого кадра, если он доступен. Если интерфейс предлагает только общий Reference, не считать его автоматически эквивалентом image-to-video.
2. Выставить **5s, 9:16, 2K**. 2K было видно в присланном интерфейсе; текущая доступность именно этого набора ещё не подтверждена. Если 9:16 определяется из PNG, проверить итоговую ориентацию. Не оставлять исходные 16:9 со скриншота. Не искать не подтверждённый для H3 режим 720p ради условной экономии.
3. Вставить промпт. Без дополнительных изображений, видеореференсов, озвучки, музыки и платного повышения разрешения. Если есть платные переключатели звука или улучшения, оставить их выключенными.
4. Пользователь подтвердил: **интерфейс не показывает количество кредитов за запуск**. Не просить повторно найти ту же цифру. Числовая смета остаётся неподтверждённой; следующий способ уточнения — действующие правила тарифа или ответ поддержки MiniMax, текст ниже. Не запускать задачу ради выяснения цены.
5. Запускать только после отдельного согласования расхода. Объём предложения — **ровно одна задача**, без автоматического второго варианта или повторной отправки при долгом ожидании.

Если указанного режима нет в текущем аккаунте, сначала уточнить доступные параметры; генерацию с другими настройками молча не подменять.

Курс кредита к доллару и полная себестоимость подписок неизвестны; числовую долларовую смету не выдумываем.

Лимит на запуск ещё не утверждён. Нельзя гарантировать потолок списания без подтверждённой цены или работающего ограничения провайдера. Резерв на повтор **не запрашивается автоматически**: сначала оценить первый результат. Если пользователь позднее отдельно разрешит один запуск с неизвестным списанием, зафиксировать именно это решение; текущий ответ о невидимой цене такого разрешения не даёт.

## Готовый запрос в поддержку MiniMax

Текст подготовлен для пользователя, **не отправлен**. Не прикладывать ключи, платёжные данные или исходный фильм. Минимальный вопрос касается текущего приложения и тарифа, не стороннего API.

> I use M plan in the MiniMax Cloud app and have 800 credits. I want to run one 5-second, 9:16, 2K image-to-video job in video-creator / MiniMax-H3. Is this configuration supported, with the uploaded image used as the actual first frame rather than only a visual reference? The UI shows no credit estimate. Do my plan credits cover this job, and what is the total credit charge including any agent/tool charges? Is there a guaranteed maximum charge or a pre-run spending cap? What is charged if the job fails or is cancelled? Please provide the current billing rules; I have not started a generation.

До ответа сохраняется подготовленный кадр и промпт; отдельный API или новую подписку для обхода непрозрачного тарифа не покупать. Число будущих роликов из 800 кредитов и цену серии пока не рассчитывать.

## Приёмка

Проба полезна, если без звука видна причинная цепочка: хвост действует → герой замечает и останавливает жестом → хвост замирает. Двигаются глаза, корпус, лапа и хвост, а не весь плоский кадр. Внешность, тёплый объёмный свет и материалы должны сохраниться.

Брак: растянутая лапа, лишний хвост или конечность, отрыв хвоста от корпуса, скольжение захвата, метла проходит сквозь хвост, щетина парит, ноги скользят, лицо меняется, мерцает шерсть, камера заменяет актёрское действие. Красивый стоп-кадр не компенсирует нечитабельный жест. При браке сначала определить одну причину; новый платный запуск без согласования не делать.

После получения MP4 проверить параметры, полное декодирование и само движение. Технический успех рендера не означает художественную приёмку. Затем решать, достаточно ли надёжны герой и хвост для полного выпуска.

## Что подтверждено об API, а что относится к аккаунту

Официальный MiniMax CLI описывает H3: длительность **4–15 секунд**, API-разрешение **2K**, загрузка первого кадра через `--image`, максимум 30 MB для изображения. Это технические пределы API, **не цена, не минимальный платёж и не описание условий M plan**.

Для прямого H3 API официальная инструкция требует совместимый Pay-as-you-go/Credit API Key; OAuth и Token Plan Subscription Key не подходят. В текущей среде нет `mmx`, его сохранённой конфигурации или привязанного `MINIMAX_API_KEY`. Из этого не следует, что ваш M plan не позволяет сделать видео в приложении. API-подключение для первой пробы не требуется и сейчас не настраивается; ключи в чат не присылать.
