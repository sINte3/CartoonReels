# Первая техническая проба

**Архив отклонённого художественного направления.** Пользователь полностью отверг визуальный уровень этой SVG-пробы. Файлы сохранены как история технической проверки; они не задают стиль будущего канала. Актуальное направление — `../../docs/ART_DIRECTION_V2.md`. ZIP сохраняет исходный снимок этапа и не содержит последующих поправок к художественной задаче.

Дата: 15 октября 2026 года. Рабочий герой «Хвост спешит помочь», оригинальная SVG-анимация, Remotion 4.0.535.

- `hero-poses.png` — рабочий дизайн в шести позах, 2400×1600.
- `tail-study-8s.mp4` — немая проба: 8 секунд, H.264, 1080×1920, 24 fps, 192 кадра. Полное декодирование без ошибок проверено.
- `tail-contact.png` — кадр с контактом хвоста и щётки.
- `motion-check.png` — пять выбранных кадров для технической проверки. Они не заменяют просмотр движения в реальном времени.
- `validation.json` — параметры видео, размеры и SHA-256 этих результатов.
- `CartoonReels.zip` — исходники, документы и результаты этого этапа; без `node_modules`, кешей, `.env` и Git-метаданных.

Откройте нужный файл на GitHub и используйте **Download raw file**. Проба не является полным выпуском «Чисто!». Звука нет намеренно. Платные генеративные API не вызывались. Разрешение пользователя распространяется на загрузку этих файлов в существующий репозиторий независимо от его видимости.
