# Исполнитель Kie для Claude Code

Скрипты PowerShell 7, которыми 8 ноября 2026 года выполнен пакет EP001 V3: 7 задач, 388 кредитов, ни одной повторной отправки. Запись исполнения — [`episodes/EP001_V3/production/`](../../episodes/EP001_V3/production/).

Это уже работающий способ отправки, опроса, загрузки и скачивания, на который ссылаются карточки эпизодов. Для нового эпизода папку копируют и адаптируют, а не пишут конвейер заново. Навык `/generate` при этом не меняется.

## Требования

- Windows, PowerShell 7, `ffmpeg`/`ffprobe` в PATH (проверено на 9.0.2), `curl.exe`, git.
- Ключ `KIE_API_KEY` в `~/.env`. Скрипты читают его в переменную процесса только на время вызова; в вывод, журнал и файлы он не попадает. Ключ и `.env` в репозиторий не класть.
- Результаты и журнал пишутся плоско в `E:\Generations`, как требует `/generate`.

## Как устроено

- Всё состояние пакета — в журнале `<префикс>_journal_<время>.jsonl` и записях попыток `<префикс>_<попытка>_<время>.task.json` в `E:\Generations`. Действует последнее `accept`/`reject` по этапу.
- Перед каждой платной отправкой (`Assert-CanCreate`) проверяется: нет ли уже записи этой попытки; нет ли незавершённой или невыясненной отправки; не исчерпаны ли лимиты созданий и повторов; сходится ли баланс с суммой списаний; помещаются ли в лимит факт, неясное, этот этап и все оставшиеся обязательные этапы.
- Намерение пишется в журнал до `createTask`, taskId — сразу после ответа. Таймаут, 5xx или ответ без taskId дают статус `unknown`: все новые платные действия блокируются до выяснения. Явный отказ (4xx) — `rejected`, сам не повторяется.
- Входные картинки загружаются на `kieai.redpandaai.co` и до `createTask` проверяются обратным скачиванием: размер, тип, SHA-256.
- Тело запроса строится только из `request_template` в `plan.json` зафиксированного коммита. SHA-256 плана и промптов сверяются.
- Повтор `<этап>-retryN` возможен только после записанного `reject` с конкретным дефектом. К промпту плана добавляется абзац правки из отдельного ASCII-файла.

## Скрипты `ep001_v3/`

| Скрипт | Платно | Что делает |
|---|---|---|
| `export-inputs.ps1` | нет | Достаёт из git файлы коммита пакета (`plan.json`, фильтр, промпты) в `inputs/` |
| `v3_activate.ps1` | нет | Один раз: сверяет план и героя, копирует промпты в `E:\Generations\refs`, пишет активацию и стартовый баланс |
| `v3_create.ps1 -Label K0 [-AddendumFile f]` | **да** | Одна отправка `createTask`; порядок K0 → K1 → A → последний кадр A → K2 → B |
| `v3_poll.ps1 -Label K0` | нет | Опрос `recordInfo` по сохранённому taskId, сверка списания с ожиданием |
| `v3_save.ps1 -Label K0` | нет | Скачивание, полное декодирование, ffprobe, громкость, лог рядом с файлом |
| `v3_decide.ps1 -Label K0 -Decision accept -Reason "…"` | нет | Решение по попытке в журнал; `accept` — только для успешной задачи с одним файлом |
| `v3_alast.ps1` | нет | Последний кадр (№ 95) принятого A в PNG для K2 и B |
| `v3_assemble.ps1 [-GainA дБ] [-GainB дБ]` | нет | 720p со звуком, копия 1080p (lanczos), тихая копия; итоговый файл появляется, только если пройдены все 11 проверок |
| `v3_balance_check.ps1` | нет | Баланс Kie против суммы списаний по записям |
| `dryrun/run_dry.ps1` | нет | Весь сценарий на моках без сети: прокси на `127.0.0.1:9`, поддельный ключ, временная папка вместо `E:\Generations`, в том числе таймаут `createTask` → запрет повтора |

Порядок, в котором выполнялся V3:

```
pwsh -File v3_activate.ps1
pwsh -File v3_create.ps1 -Label K0; pwsh -File v3_poll.ps1 -Label K0; pwsh -File v3_save.ps1 -Label K0
pwsh -File v3_decide.ps1 -Label K0 -Decision accept -Reason "…"   # после осмотра результата
# то же для K1 (при дефекте: reject, затем K1-retry1 -AddendumFile …), A, v3_alast.ps1, K2, B
pwsh -File v3_assemble.ps1 -GainB 5
pwsh -File v3_balance_check.ps1
```

Перед новым запуском сначала `pwsh -File export-inputs.ps1`: 8 ноября входные файлы лежали во временной папке сессии.

## Что привязано к EP001 V3

Для нового эпизода скопировать `ep001_v3/` в `<эпизод>/` и поменять:

- `v3_lib.ps1`: `$Pfx`, `$Cap`, `$Commit`, `$PlanSha`, `$Hero`/`$HeroSha`, `$PriceCr`, `$MaxCreates`, `$MaxRetries`, `$Stages` (`after` — цена оставшихся обязательных этапов), проверку тела в `Build-Body` (сейчас допускает только видео 4 с), `uploadPath`, текст лога «пакет EP001 V3, лимит 600»;
- `v3_activate.ps1`: текст разрешения пользователя и проверенные цены;
- `v3_create.ps1`: граф зависимостей этапов и состав референсов;
- `v3_alast.ps1`: длительность A (4 с, 96 кадров);
- `v3_assemble.ps1`: ожидаемые 192 кадра и 8 с, имена выходов; 10-процентное укрупнение B зашито в фильтре V3;
- `export-inputs.ps1`: путь `episodes/EP001_V3/`;
- `dryrun/`: ожидаемые цены, состав тел запросов и проверки.

## Скрипты `ep002/` — так сделан EP002

8 ноября 2026 года по ним выполнен EP002 «Силач понарошку»: 7 задач, 429 из 640 кредитов. Запись исполнения — [`episodes/EP002/production/`](../../episodes/EP002/production/). Сухой прогон `ep002/dryrun/run_dry.ps1` до первого расхода — 67 PASS, 0 FAIL.

Отличия от `ep001_v3/` (имена скриптов `ep002_*.ps1`, префикс `CartoonReels_EP002`):

- `ep002_lib.ps1`: лимит 640, коммит `e1fcc86`, цены и длительности по этапам (`$Stages.<этап>.price/duration`, видео 41 кр/с); проверка тела видео принимает только длительность своего этапа (A 4, B 5); `uploadPath=cartoonreels/ep002`; тестовый режим через `$env:EP002_TEST_GEN`;
- промпт в теле сравнивается с файлом **точно**: промпты EP002 заканчиваются переводом строки, и прежнее `TrimEnd` давало ложный отказ; абзац правки добавляется после пустой строки;
- `ep002_create.ps1`: K0 ← герой; K1 ← K0, герой; A ← K0 → K1; K2 ← последний кадр A, K0, герой; B ← последний кадр A → K2. Последний кадр A принимается, только если извлечён из текущего принятого A;
- `ep002_alast.ps1`: кадр 95 той же цепочкой, что первая строка фильтра монтажа; md5 выбранного кадра сверяется с кадром 95 цепочки;
- `ep002_assemble.ps1 [-GainA дБ] [-GainB дБ] [-MeasureOnly]`: 216 кадров / 9 с без укрупнения; `-MeasureOnly` печатает громкость используемых отрезков (A 0–4 с, B 0–5 с) и ничего не собирает. Усиление выбирать по событиям: у EP002 выпуск собран с `-GainA 5 -GainB -0.5`, потому что интегральную громкость B задирает удар о пол.

Для EP003 копировать `ep002/`, а не `ep001_v3/`.

- `$Dl` — была временная папка сессии, теперь `inputs/` или `$env:KIE_EXEC_INPUTS`;
