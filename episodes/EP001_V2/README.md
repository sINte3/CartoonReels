# EP001 V2 — «Сам попросил»

6 ноября 2026 года, Asia/Tashkent. **Сценарий и производственный пакет подготовлены. Финальный новый план ещё не сгенерирован; расход не разрешён.**

## История

Маленький рыжий зверёк сердито показывает работающему хвосту «стоп». Хвост послушно прекращает помогать: разжимает захват метлы и расслабляется. Наклонённый черенок опирается на уже поднятую лапу героя. Герой пытается убрать лапу, но метла тут же начинает падать — приходится подпереть её обратно. Герой смотрит на отдыхающий хвост: сам отказался от помощи и теперь остался с работой.

Рабочее название — только название проекта/публикации, без надписи внутри кадра. Реплики не нужны. Хвост действует послушно, не пытается ударить или наказать хозяина. Шутка строится на смене роли: командующая лапа превратилась в подпорку для метлы.

Длина первого микропилота — **7 секунд, два плана**. Готовую актёрскую пробу используем как завязку. Старый сценарий с ковриком остаётся историей разработки; эту версию ставим под уже проверенные внешность, свет и движение.

## Проверка результата и риски

Новое действие, которого ещё не проверяли: хвост разжимает захват, а один черенок переходит на опору уже поднятой лапы. Это реальный риск генерации. Нельзя обещать получение нужного гэгa с первой попытки или закладывать скрытые повторы.

Обязательно: хвост заметно отпустил метлу и остаётся одной связной частью тела; у героя одна метла; черенок опирается на лапу, щетина — на пол; герой реагирует на новую обязанность; анатомия, лицо и свет не распадаются. Метла не бьёт героя по лицу, лапа не удлиняется и не проходит сквозь черенок.

Допустимая уступка: движение «попытался убрать лапу — вернул» может оказаться слабее текста. Если передача опоры и финальное понимание уже ясно читаются без звука, сначала оценить монтаж, не заказывать повтор автоматически. Если хвост не отпускает метлу или предмет остаётся висеть без опоры, финал не получился — не объявлять ролик готовым по одному статусу `success`.

Пиксельное совпадение с загруженным первым кадром не гарантируется: предыдущая проба его не сохранила. Склейку оформляем как смену крупности: после получения плана 2 — постоянное монтажное укрупнение на 10%, без движения камеры и морфинга. Это уменьшает ощущение случайного скачка, но не исправляет явное изменение внешности.

## Сборка после приёмки плана 2

Сначала проверить оба MP4: вертикаль 9:16, нужная длительность, декодирование, отсутствие дефектов движения. При неожиданном формате не растягивать изображение молча. Путь к полученному клипу взять из реального результата, не выдумывать.

Пример PowerShell: `$shot1` — скачанная трёхсекундная монтажная версия; `$shot2` — новый принятый клип; `$master` — новый файл в `E:\Generations`. Следующий фильтр проверен здесь на технической подстановке вместо плана 2; настоящий финал ещё не снят.

```powershell
$filter = '[0:v]trim=start=0:end=3,setpts=PTS-STARTPTS,fps=24,setsar=1[a];[1:v]trim=start=0:end=4,setpts=PTS-STARTPTS,fps=24,scale=792:1408,crop=720:1280:36:64,setsar=1[b];[a][b]concat=n=2:v=1:a=0[v]'
ffmpeg -i $shot1 -i $shot2 -filter_complex $filter -map '[v]' -an -c:v libx264 -crf 18 -movflags +faststart $master
if ($LASTEXITCODE -ne 0) { throw 'Сборка EP001 не удалась' }
```

Черновой мастер: 7 секунд, 720×1280, 24 fps, 168 кадров, H.264. Экспорт 1080×1920 при необходимости — обычное масштабирование, не обещание дополнительной детализации. Никаких титров, заставки и водяного знака проекта поверх действия.

История должна читаться без звука. После окончательного монтажа допустимы тихий деревянный стук при переходе опоры и лёгкий скрип при попытке убрать лапу. Музыка/Suno и голос не нужны; новые аудиогенерации не включены. Звуки и финальную дорожку пока не создавали.
